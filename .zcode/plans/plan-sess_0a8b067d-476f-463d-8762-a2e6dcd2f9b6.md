## 重写 `docs/backend/structure.md`

### 核心变更

将文档从**领域包组织**（dictionary/, word/, review/, handler/）重写为**分层架构**（app/, handler/v1/, service/, repo/, domain/, apperr/, infra/），与 `docs/specs/backend/Go 单体应用架构规范.md` 对齐。

### 保留的领域特定内容

保留 LexiLoop 独有的设计决策（从当前文档和 domain docs）：
- `cmd/import-ecdict/` 独立导入程序
- `DictionaryProvider` 在线补充接口（从 enrichment.md 引用）
- `Sampler` 抽样接口和 `weight.go` 权重计算
- 释义三层取值（custom ?? review ?? raw）
- 软删除（`deleted_at`）
- MVP 不过度设计的原则

### 新目录结构

```text
cmd/
  import-ecdict/           离线导入：ECDICT CSV → dictionary_entries
    main.go

internal/
  app/                     组合根
    provider.go            组件构造函数
    routes.go              中间件与路由挂载
    server.go
  domain/                  领域模型（无 ORM/基础设施依赖）
    dictionary.go          DictionaryEntry + 业务方法
    user_word.go           UserWord + 业务方法
    review.go              ReviewSession, ReviewItem
    errors.go              领域 sentinel errors
  repo/                    无状态数据访问适配器
    dictionary.go
    user_word.go
    review.go
    internal/schema/       bun ORM 映射（仅 repo 可导入）
      dictionary.go
      user_word.go
      review.go
  service/                 用例编排
    word.go                WordService（导入/查询/更新释义/软删除）
    dictionary.go          DictionaryService（Lookup/Enrich）
    review.go              ReviewService（开始/提交/获取 session）
    sampler.go             抽样接口 + SimpleWeightedSampler
    weight.go              CalculateWeight 实现
  handler/
    router.go              路由入口
    v1/
      word.go              词 handler
      review.go            复习 handler
      dto/
        word.go            请求/响应 DTO
        review.go
    middleware/             HTTP 横切
      auth.go
      cors.go
      logger.go
  apperr/                  类型化应用错误
    error.go
  infra/                   基础设施
    config/
    database/
```

### 依赖方向

```
app → handler/v1 → service → repo → domain
service → apperr
handler/v1 → apperr
app → infra（组装）
```

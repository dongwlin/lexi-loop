# LexiLoop

## 项目名称

英文名：LexiLoop
中文名：词环

## 名称含义

**LexiLoop** 可以拆成两部分理解：

- **Lexi**：来自 _lexicon_（词汇、词典）或 _lexical_（词汇的），在产品命名里常被用来表达「单词、词汇学习」。
- **Loop**：循环、闭环，正好对应生词需要「反复出现—回忆—巩固—再次复习」的过程。

所以 **LexiLoop** 可以理解成：**「词汇循环复习系统」**、**「让单词进入记忆闭环」**。

## Slogan

**让每个生词，都有自己的复习节奏。**  
_Learn. Recall. Loop._
